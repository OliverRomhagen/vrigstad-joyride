# Docs

Proposals, decisions, research and notes for Vrigstad Joyride. Plain Markdown: read it on GitHub, in your editor, or open this folder as an [Obsidian](https://obsidian.md) vault.

*This folder is itself a proposal: see [proposals/0002-docs-vault.md](proposals/0002-docs-vault.md).*

| Folder | What goes there |
|---|---|
| [proposals/](proposals/) | Ideas for the team to discuss, one file each, with a `status` |

## Opening it in Obsidian

Open vault → *Open folder as vault* → pick `docs/`. The committed `.obsidian/app.json` makes Obsidian write normal relative links, so they keep working on GitHub. Don't commit your workspace layout; `.gitignore` already skips it.
