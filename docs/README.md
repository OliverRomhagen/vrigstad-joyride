# Docs

Notes about the game in plain Markdown, in two kinds:

- `lore/`: the places and people of Vrigstad, for players. Each file is a page on the wiki (`wiki/`), at its path in `lore/` without `.md` (`lore/places/torget.md` is `/places/torget`). It starts with YAML frontmatter: a `title` (required), `kind` and `summary`; the rest of the frontmatter is what the page's infobox shows (a place's `position`, and its `start` when "Drive here" should start you somewhere else, a character's or an animal's 3D `model`, and on any page `tables`, tables of the game's own numbers from `wiki/src/lib/game-tables.ts`, which come after the prose in the order listed, each under its own heading: write the prose so that reads right), and the body is the prose. Each `kind` (`place`, `character`, `animal`, or `note` when there is none) says which fields it takes, in `wiki/src/lib/lore-index.ts`; the wiki's build fails on a kind it doesn't know, or a field of the wrong shape, naming the file. A new folder is a new section of the wiki, shown under its folder's name; give it a better one, and its place in the sidebar, in `wiki/src/lib/sections.ts`. Pages go one folder deep: a folder inside a folder fails the build. The wiki doesn't tell everything: jokes, surprises and things better found in the game stay out of it, or get a hint at most.
- Everything else here (the console's spec, the vehicle fleet, the audio proposal) is internal, for the people who make the game, and isn't published.

Links between lore pages are ordinary relative Markdown links (`[Torget](../places/torget.md)`), so they work on GitHub and on the wiki. A page of the wiki that isn't a file here (the map) is linked by its address on the live wiki (`https://oliverromhagen.github.io/vrigstad-joyride/wiki/map`), which the wiki turns into its own link. A link starting with `/`, or from a lore page to an internal one, fails the wiki's build.
